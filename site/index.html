What it does

Four things, done properly.

✓

Tasks

Type “Gym tomorrow 6pm” and it schedules itself. Break work into steps you can tick off straight from the list, set priorities, tags and repeats.

↻

Habits

Daily, weekly or monthly, with reminders that fire on your device. A seven-day strip on every habit shows whether you actually kept it up.

⚡

Routines

Bundle the steps you repeat — your morning, a workout, a shutdown ritual — and drop the whole set into today in one tap.

◔

Review & insights

Replan everything overdue into today's free slots, catch missed habits, and see how the week actually went.

How to install

NizKarya isn't on the Play Store yet, so Android asks for permission the first time.

  1. Tap Download for Android above to get the APK.
  2. Open the downloaded file. Android will ask to allow installs from your browser.
  3. Choose Settings → Allow from this source, then go back and tap Install.
  4. Sign in with Google or an email address, and you're in.
Every release is signed with the same key, so new versions install straight over the old one and keep your data. Reminders run entirely on your device — no notification server is involved.
